# Animal_identifier
This can identify what animal a photo is using a CNN (Convolutional Neural Network). It was trained off of 90 classes, meaning it can identify 90 different animals. However, it uses a pre-trained base model so that the training times are faster because its already partially trained. Rather than totally untouching the training model, we train 2 of the visual features (The part-of-object and object.). This allowed our actual model to have more accuracy.
